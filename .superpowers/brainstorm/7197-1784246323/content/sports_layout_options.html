Interactive Sports Matchday Layout Options

We want to reduce the vertical height of Matchday posts in the feed while making them interactive and visually engaging. Select your preferred style:

A

Tabbed Dashboard Layout (Recommended)

Organizes Matchday data into three clickable tabs: 📅 Results, 📈 Movers, and 📝 Summary. This keeps the feed extremely compact (only 200px tall initially) and allows the user to explore what they want.

B

Compact Grid Layout

Shows matches in a two-column grid on desktop, cutting the height in half. Movers are listed in a small scrolling shelf, and the narrative summary is placed at the bottom under an expandable toggle.

C

Progressive Disclosure List

Keeps the single-column list but only displays "Key Matches" (upsets, top table clashes) upfront. The rest of the results are collapsed under a "Show All Results" smooth expander.
