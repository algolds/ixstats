National Issues Admin Panel Redesign

Select the visual layout that best fits your workflow for global engine controls, template CRUD, and active issue monitoring.

A

Split-Screen Column Layout (Recommended)

Sticky configuration sidebar on the left; inline scrollable template manager on the right. Details & CRUD are handled in drawer sidebars or modals.

B

Tabbed Dashboard Layout

A top navigation bar switches between tabs (Templates, Engine Settings, Active Issues). Reduces cognitive load by separating features, but hides information.

C

Three-Panel Workspace Layout

Left panel: Engine controls & stats; Middle panel: Scrollable template list; Right panel: Selected template details/editor. Great for heavy CRUD operations.

Pros & Recommendations

  • Option A: Best balance of space. Keeps controls sticky so administrators can easily trigger manual evaluations or seed defaults while filtering and scanning.
  • Option B: Simplest UI structure. Great if page space is constrained, but requires switching tabs to review active issues or run stats.
  • Option C: Ultimate workflow efficiency. Eliminates modals/drawers for CRUD, rendering the editor panel side-by-side with templates, ideal for editing JSON triggers.

Cons & Risks

  • Option A: Screen space on smaller tablets might feel tight; requires sidebar to be collapsible on mobile.
  • Option B: Disconnects templates from diagnostics, requiring duplicate state reload or manual sync.
  • Option C: Needs at least 1200px width to display all three panels legibly without horizontal overflow.
