Narrator Admin Panel Layout

Select the visual layout that works best for managing and testing the system-wide AI Narrator.

A

Tabbed Navigation Layout (Recommended)

Organizes the dashboard into three distinct tabs: 1. API Settings (API keys, URLs, model selection), 2. Playground (select country, write test prompts, hit API, and see live Paradox outcomes), and 3. Cache Lab (view cache stats, clean entries, inspect cached keys). Fits existing admin tab styles.

B

Split Workspace Layout

A side-by-side split screen: the left column houses all configuration settings and cache controls, while the right column acts as a persistent live playground. Great for rapid prompt tweaking and seeing results immediately without switching tabs.

Tabbed Pros & Cons

  • Clean, focused view of each feature area
  • Consistent with existing admin panels (like Myleague/Storyteller)
  • Requires switching tabs to change configuration and then test

Split Pros & Cons

  • Fast workflow — edit a setting and test it on the same screen
  • Perfect for large screens, but may feel cramped on smaller viewports
  • Different from standard admin visual hierarchy
