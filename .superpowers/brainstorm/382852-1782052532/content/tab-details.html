Tabbed Layout Sections

Here is the detailed functional breakdown for each of the three tabs. Select your preferences for additional features.

Tab 1: API Settings & Controls
  • Global Toggle: Enable/disable AI flavorization console-wide.
  • Provider Selection: Dropdown to switch between Nvidia (DeepSeek), OpenRouter (Llama 3.1), or OpenAI (GPT-4o-mini).
  • API Credentials: View status of configured API keys, with inputs to save overrides to `SystemConfig`.
  • Parameters: Slider controls for LLM temperature and max tokens.
Tab 2: Live Narrative Playground
  • Two Input Modes:
    • Real Data Mode: Select a Country → Select target event type (Issue/Policy/Decision) → Select concrete database item (e.g. Issue: "High Unemployment").
    • Sandbox Mode: Blank fields for custom Title, Description, and raw Country Metrics JSON.
  • Live Run Button: Submits to backend and shows a live loading shimmer.
  • Paradox Card Previewer: Renders the actual generated text in the real styled Paradox card wrapper.
Tab 3: Cache Lab & Stats
Metrics:
  • Total entries cached
  • API savings / hit rate percentage
  • Average LLM latency
Actions:
  • Clear Cache button (wipes narrator:custom keys)
  • List of 10 most recent cached event IDs
