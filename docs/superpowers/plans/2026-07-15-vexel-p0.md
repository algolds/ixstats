# Vexel P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Vexel heraldry generator and editor at `/labs/vexel` — a structured heraldic achievement composer with Wikimedia Commons charge library, blazon generation, procedural generation, and a public Heraldic Authority registry.

**Architecture:** Panel-based structured editor (Figma-style layers) rendering full heraldic achievements. Composition model (JSON) → Validation Engine → Layout Engine → SVG Renderer → Export Pipeline. Blazon generator produces formal English text from composition. tRPC backend with Prisma models. Existing `commons.ts` router provides Wikimedia API bridge.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript 5.9, tRPC 11, Prisma 6.19, Zod v4, Tailwind CSS v4

## Global Constraints

- Package manager: `bun` (never npm/yarn/pnpm)
- Zod v4 (import from `zod/v4`, NOT `zod`)
- Tailwind CSS v4 (`@theme` directives, CSS-based config)
- tRPC 11 patterns (match existing router conventions in `src/server/api/routers/`)
- Router registration uses `safeRouter()` wrapper in `src/server/api/root.ts`
- Files must stay ≤700 lines (arch-guard ceiling)
- Path aliases: `~/` = `./src/`, `@/` = `./src/`
- Unused vars: prefix with `_`
- DB writes are blocked in dev by default (`db:push:force` for schema changes)
- Prisma schema files live in `prisma/schema/` — new domain gets its own `.prisma` file
- Labs pages use headless-nav layout at `src/app/labs/layout.tsx`
- Existing `commonsRouter` at `src/server/api/routers/commons.ts` provides Wikimedia API
- Do NOT run `tsc --noEmit` globally or full typecheck scripts

- [ ] **Step 5: Implement `src/lib/heraldry/blazon.ts`**

```typescript
export function generateBlazon(comp: HeraldryComposition): string {
  const parts: string[] = [];
  parts.push(blazonField(comp.shield.field));
  for (const ord of comp.shield.ordinaries) {
    parts.push(blazonOrdinary(ord));
  }
  for (const charge of comp.shield.charges) {
    parts.push(blazonCharge(charge));
  }
  if (comp.externals) {
    parts.push(blazonExternals(comp.externals));
  }
  return parts.filter(Boolean).join("; ");
}
```

Key: Field is always first. Ordinaries use "a [type] [tincture]". Charges use "[count] [name] [attitude] [tincture]". Capitalize first word. Use heraldic number words (one→"a", two→"two", three→"three"). Tinctures are capitalized in blazon text.
