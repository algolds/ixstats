# Design Spec: Sports Matchday Feed & Discord Redesign

This document outlines the design and implementation specifications for redesigning how Matchday bulletins are presented on both the ThinkPages web feed and the Discord mirror feed.

## Overview

The current Matchday posts generated by `SportsNews` are displayed as a long vertical stack of scores and table updates. This clutters the ThinkPages social feed and results in excessively tall text blocks on Discord. 

This redesign:
1. Refactors the ThinkPages web card ([SportsBulletinCard.tsx](file:///home/jxsig/projects/ixstats/src/components/thinkpages/SportsBulletinCard.tsx)) into a compact, tabbed dashboard with a side-by-side grid.
2. Formats the Discord mirror posts into rich embeds featuring code-blocked score tables, table mover highlights, custom color-coding, and direct website links.

---

## 1. Web Layout Redesign (ThinkPages Card)

Inside [SportsBulletinCard.tsx](file:///home/jxsig/projects/ixstats/src/components/thinkpages/SportsBulletinCard.tsx), the default matchday view is replaced by a tabbed interface.

### Active State & Tab Controls
- Uses React `useState` to track the active tab: `'results' | 'movers' | 'summary'`.
- Default tab is `'results'`.
- Tab headers will styled using **Facet** principles (subtle glass buttons, active/inactive indicator states, amber colors for matches, and clean hover state scaling).

### Tab A: Results (📅 Matches)
- Matches will render in a two-column grid on desktop (`grid grid-cols-1 md:grid-cols-2 gap-2`) and single-column on mobile.
- Each match is rendered in a pill-shaped row with background `bg-black/25` or `bg-white/[0.01]`.
- Displays home team on left, away team on right, and score in the center.
- Upsets are highlighted with a glowing amber/yellow star (`⭐`) and subtle outline border.
- Winner is bolded, and team names link to their club profile page if `id` is present.

### Tab B: Movers (📈 Standings Movers)
- Shows a list of rank movements.
- Renders green up arrows (`▲`) and red down arrows (`▼`) with custom font coloring.
- Links to club pages are maintained.
- If there are no movers, displays a placeholder message: *"No standing changes recorded for this matchday."*

### Tab C: Commentary (📝 Summary)
- Displays the LLM-generated narrative summary in an italicized blockquote layout.
- If no summary is available, the "Summary" tab is hidden entirely.

## 2. Discord Embed Redesign

For Discord mirroring, we intercept the formatting inside [formatThinkPagesEmbed](file:///home/jxsig/projects/ixstats/src/lib/discord-ixtwitter-sync.ts) to construct a dedicated, visually compelling embed when sports bulletin JSON comments are detected.

### Data Extraction & Interception
- [cleanPostContent](file:///home/jxsig/projects/ixstats/src/lib/thinkpages-discord-feed.ts) is bypassed when passing content to `formatThinkPagesEmbed`, ensuring the JSON comment `<!-- sports-bulletin:... -->` remains intact for parsing.
- `formatThinkPagesEmbed` parses this comment using `parseSportsBulletin(post.content)`.
- Normal posts fall back to standard HTML-to-Markdown conversion.

### Rich Embed Properties
- **Color**: Selects a custom color based on the sport (e.g. grass green `#22c55e` for soccer, court orange `#f97316` for basketball, ice blue `#38bdf8` for hockey) or a fallback gold/yellow branding color (`#f59e0b`).
- **Author**: Retains the `SportsNews` bot branding and avatar.
- **Title**: `⚽ [League Name] — Matchday [X]` (or corresponding sport emoji).
- **Description**: Displays a brief intro message followed by a clean **Structured Code Block Table**:
  ```text
  Urcea      2 - 1  Gaelia
  Apaturia   0 - 3  Daxia     [Upset ⭐]
  Coria      1 - 1  Olaria
  ```
- **Movers Field**: Adds a custom Markdown field `📈 Table Movers` summarizing standing deltas:
  ```text
  ▲ **Daxia** (+3 spots, 7th → 4th)
  ▼ **Apaturia** (-2 spots, 2nd → 4th)
  ```
- **Narration/Summary Field**: Adds a field for the LLM summary blockquote if narration is enabled.
- **Deep Links**: Appends a clear button/link at the bottom of the embed pointing back to the league detail page: `[View Matchday & Standings on IxStates](https://ixwiki.com/projects/ixstates/myleague/[id])`.
