# IxStates Documentation Hub

The index for IxStates architecture, systems, operations, specifications, reference and research. Version information
comes from the [Version Registry](../src/lib/buildVersion.ts) — see [Versioning & Release Architecture](reference/revision.md).

> Audited 2026-10-27, after release 1.5 reached production. Internal platform **1.5.0 "Lobster Crosby"**; the public
> numbering restarted at **1.0.0 "Lobster Crosby" (Stable)** (`VERSIONS` vs `INTERNAL_VERSIONS` in
> [buildVersion.ts](../src/lib/buildVersion.ts); see [revision.md](reference/revision.md)). IxStates runs at
> **https://beta.ixwiki.com** (no base path); **maps.ixwiki.com** is the app's `/maps` page; WikiOS v1 is live with
> two-way sync with classic MediaWiki. Branches: `rose-garden` nightly → `development` stable-experimental → `master`
> production ([contributing](processes/contributing.md#branches)). Retired docs are kept in [history/](history/README.md);
> `plans/` and `docs/archive/` are local-only maintainer folders, not in the repository.
