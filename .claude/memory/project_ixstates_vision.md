## Platform Pillars (March 2026)

1. **Wiki (IxWiki)** — The canonical truth and origin point for all lore/worldbuilding. Everything flows FROM the wiki.
2. **IxWorld/Maps** — The physical and tangible representation of the shared world canon. The visual layer of truth.
3. **MyCountry** — The real-time manifestation of a country existing within an interconnected/shared world of interaction. The gameplay layer.
4. **ThinkPages** — The meta social media network that works from both a worldbuilding POV and as a gameplay mechanism.
5. **Forum** — The community foundation. Currently underdeveloped but part of the product vision.
6. **IxStates** — The actual main vision. IxStats was always just the MVP/test to get the stats engine working. IxStates is intended to be an actual product.

**Why:** The user wants to refactor the platform around this philosophy — ensuring lore is the canonical source, and all other systems serve and surface that lore in contextually appropriate ways.

**How to apply:** Every feature decision should be evaluated against: "Does this serve the lore-first pipeline? Does it strengthen the connections between wiki → maps → mycountry → thinkpages → forum?"
